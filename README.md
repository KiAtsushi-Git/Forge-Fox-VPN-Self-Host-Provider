**ForgeFox VPN Provider** — это центральная веб-панель управления для вашей VPN-сети.
Позволяет разворачивать новые VPN-сервера (Edge Nodes) в один клик по SSH, управлять тысячами пользователей, выдавать лимиты по трафику и времени, а также генерировать ссылки-подписки для десктопного и мобильного клиента.

Вдохновлена такими проектами как `3x-ui` и `Marzban`, но построена на **Python (FastAPI)** + **SQLAlchemy** + **asyncssh** — без этапа компиляции, образ Docker собирается за секунды.

## 🚀 Возможности

- **Полное управление через Web-UI:** Удобная панель на Vue 3 + TailwindCSS.
- **Поддержка нескольких БД:** Работает как с **SQLite** (для быстрых установок "в один файл"), так и с **PostgreSQL** (для огромных сетей). База от старой Rust-версии подхватывается автоматически.
- **Мульти-нодовость:** Управляйте десятками серверов по всему миру из одной панели.
- **Статус установки VPN-стека:** Панель сама определяет, установлен ли на ноде `forgefox-bridge`, показывает бейдж «VPN не установлен» и ставит стек одной кнопкой (или предлагает сразу после добавления ноды).
- **Мониторинг в реальном времени:** CPU, RAM, диск, аптайм, скорость канала (kbps), активные SSH-сессии пользователей — по каждой ноде.
- **Детейл-модалка ноды:** Клиенты ноды, активные сессии, мониторинг, статус установки, перезагрузка ноды — всё в одном окне.
- **Интерактивные графики:** Трафик сети за 14 дней и персональный график трафика каждого клиента (Chart.js).
- **Лимиты пользователей:** Ограничения по трафику (GB) и сроку действия подписки, пресеты срока (+1 неделя / +1 месяц / +3 месяца), продление в один клик.
- **Автоблокировка:** Фоновые задачи сами блокируют клиентов, превысивших лимит трафика или срок подписки.
- **Массовые операции:** Bulk-создание клиентов, экспорт/импорт JSON, генерация QR-кода подписки прямо в панели.
- **Telegram-бот:** Уведомления админу (истечение подписок, лимиты, ноды офлайн) + команды `/users`, `/add`, `/del`, `/sub`, `/stats`.
- **Журнал аудита:** Все действия админа пишутся в лог и видны в панели.
- **Темы оформления:** 🌙 Dark, 🌌 Midnight, ☀️ Light (переключаются прямо в UI).
- **Генерация подписок:** Ссылки `/sub/:id` для автоматической настройки VPN-клиентов.
- **Самообновление:** Панель проверяет новые коммиты и пересобирает себя кнопкой из UI.

## 🛠 Быстрая установка

Вы можете установить панель на любой чистый Ubuntu/Debian сервер всего одной командой:

```bash
curl -sL https://raw.githubusercontent.com/KiAtsushi-Git/Forge-Fox-VPN-Self-Host-Provider/main/install.sh | bash -s -- --db sqlite --user admin --pass secret
```

**Параметры:**
- `--db`: `sqlite` (по умолчанию) или `postgres`.
- `--user`: Логин администратора для входа в панель.
- `--pass`: Пароль администратора.

После установки панель будет доступна по адресу `http://<IP_вашего_сервера>:8080`.

## 🖥 Запуск из исходников (Для разработчиков)

Требуется **Python 3.11+**.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/KiAtsushi-Git/Forge-Fox-VPN-Self-Host-Provider.git
   cd Forge-Fox-VPN-Self-Host-Provider
   ```

2. Создайте окружение и запустите:
   ```bash
   python -m venv .venv
   . .venv/bin/activate            # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ADMIN_USER=admin ADMIN_PASS=secret python -m app.main
   ```
   *По умолчанию создастся база данных SQLite `forgefox.db` прямо в папке проекта. Порт задаётся переменной `PORT` (по умолчанию 8080).*
