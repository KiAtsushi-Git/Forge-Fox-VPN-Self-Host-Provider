**ForgeFox VPN Provider** — это высокопроизводительная центральная веб-панель управления для вашей VPN-сети. 
Позволяет разворачивать новые VPN-сервера (Edge Nodes) в один клик по SSH, управлять тысячами пользователей, выдавать лимиты по трафику и времени, а также генерировать ссылки-подписки для десктопного и мобильного клиента.

Вдохновлена такими проектами, как `3x-ui` и `Marzban`, но построена на безопасном и молниеносном **Rust (Axum)** + **SQLx**.

## 🚀 Возможности

- **Полное управление через Web-UI:** Удобная панель на Vue 3 + TailwindCSS.
- **Поддержка нескольких БД:** Работает как с **SQLite** (для быстрых установок "в один файл"), так и с **PostgreSQL** (для огромных сетей).
- **Мульти-нодовость:** Управляйте десятками серверов по всему миру из одной панели.
- **Интерактивные графики:** Мониторинг пропускной способности (Chart.js).
- **Лимиты пользователей:** Настройка ограничений по трафику (GB) и сроку действия подписки.
- **Темы оформления:** 🌙 Dark, 🌌 Midnight, ☀️ Light (переключаются прямо в UI).
- **Генерация подписок:** Формирование ссылок `/sub/:id` для автоматической настройки VPN-клиентов.

## 🛠 Быстрая установка

Вы можете установить панель на любой чистый Ubuntu/Debian сервер всего одной командой:

```bash
curl -sL https://raw.githubusercontent.com/KiAtsushi-Git/Forge-Fox-VPN-Self-Host-Provider/main/install.sh | bash -s -- --db sqlite --user admin --pass secret
```

**Параметры:**
- `--db`: `sqlite` (по умолчанию) или `postgres`.
- `--user`: Логин администратора для входа в панель.
- `--pass`: Пароль администратора.

После установки панель будет доступна по адресу `http://<IP_вашего_сервера>:8080`.

## 🖥 Сборка из исходников (Для разработчиков)

Требуется **Rust** и **Cargo**.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/KiAtsushi-Git/Forge-Fox-VPN-Self-Host-Provider.git
   cd Forge-Fox-VPN-Self-Host-Provider
   ```

2. Запустите в режиме разработки:
   ```bash
   cargo run
   ```
   *По умолчанию создастся база данных SQLite `forgefox.db` прямо в папке проекта.*
